# 实验八：H1上半身真机命令仿真验证

## 实验目的

在连接真机前，对H1剩余九个上半身关节的正式采集动作做软件闭环验证：

- 左右肘；
- 左右肩俯仰；
- 左右肩侧摆；
- 左右肩旋转；
- 腰部 `torso_joint`。

验证使用Holosoma真机采集器中的同一个 `H1SysidPlan`，包括6秒准备姿态、
2秒稳定、50 Hz零阶保持命令、实验段、6秒回零和1秒最终保持。程序不初始化
DDS，不会发布 `rt/lowcmd`。

## 仿真模型与碰撞检查

源模型为：

```text
robot_model/h1/h1_calibrated_lower_body.xml
```

预览器生成保留碰撞几何的固定基座位置控制模型。直接相邻的运动学连杆之间
显式加入MuJoCo `exclude`，避免骨盆与腰部等相邻网格的设计重叠产生虚假接触
力；手臂与躯干、左右手臂以及其他非相邻连杆之间的碰撞仍然启用并作为失败
条件。该修改修复了原预览器使用无碰撞辨识模型、导致“自碰撞检查”实际无效
的问题。

准备姿态与真机采集器保持一致：双腿悬空屈曲并侧向分开，左右肩俯仰0.20
rad、肘关节0.32 rad，其余肩关节为0。

## 正式动作设计

每个关节运行一次正负阶跃和一次分段组合正弦。组合正弦频率为0.5、1、2 Hz，
每段10秒，段间保持2秒。

| 关节组 | 正负阶跃幅度 | 0.5/1/2 Hz幅度 |
|---|---:|---:|
| 左右肘 | 0.05 rad | 0.05 / 0.04 / 0.025 rad |
| 左右肩俯仰 | 0.05 rad | 0.05 / 0.04 / 0.025 rad |
| 左右肩侧摆 | 0.02 rad | 0.03 / 0.025 / 0.015 rad |
| 左右肩旋转 | 0.04 rad | 0.04 / 0.035 / 0.02 rad |
| 腰部 | 0.03 rad | 0.03 / 0.025 / 0.015 rad |

肩侧摆初始测试使用0.04 rad。仿真发现左肩约在-0.0373 rad、右肩约在
+0.0373 rad时上臂内侧接触躯干。将平滑正弦低频幅度降到0.03 rad后不再
接触，但0.03 rad不连续阶跃的瞬态超调仍会短暂越过该边界，因此正式阶跃
进一步降到0.02 rad。这是根据模型几何和瞬态响应得到的动作约束，不是任意
缩小幅度。

## 验收条件

每组动作必须同时满足：

- 指令覆盖目标中心的正负两个方向；
- 全部19关节最大跟踪误差不超过0.12 rad；
- 任一关节距离限位至少0.10 rad；
- 没有非相邻连杆自碰撞；
- 回零后的目标关节误差不超过0.05 rad；
- 全部状态为有限值，仿真正常结束。

## 结果

最终18/18组通过。下表为目标关节的最大跟踪误差，单位rad。

| 关节 | 阶跃 | 组合正弦 |
|---|---:|---:|
| left elbow | 0.05844 | 0.02267 |
| right elbow | 0.05844 | 0.02267 |
| left shoulder pitch | 0.05037 | 0.02580 |
| right shoulder pitch | 0.05037 | 0.02580 |
| left shoulder roll | 0.02067 | 0.01521 |
| right shoulder roll | 0.02070 | 0.01543 |
| left shoulder yaw | 0.03998 | 0.01203 |
| right shoulder yaw | 0.03998 | 0.01178 |
| torso | 0.02992 | 0.01132 |

整体检查结果：

- 最大的全关节跟踪误差为0.06132 rad，低于0.12 rad阈值；
- 最小关节限位余量为0.30856 rad；
- 最大目标关节速度为0.83842 rad/s；
- 最大回零误差绝对值为0.01044 rad；
- 正式18组均无非相邻自碰撞；
- 所有轨迹均无NaN或Inf。

人工检查了左肘组合正弦、肩侧摆阶跃和腰部组合正弦曲线。准备、激励、段间
保持和回零阶段连续，2 Hz段响应有限，没有隐藏振荡或异常漂移。

## 结论和边界

实验八的软件动作验证完成，可以进入实验九的左肘真机小规模试采。正式真机
前仍需人工确认吊带、线缆和现场空间，因为MuJoCo只能检查机器人自身几何，
不能表示真实吊装带、电缆和周围设备。仿真中的关节正负方向与MJCF一致，但
第一次真机动作仍应由操作者观察并确认物理方向。

实验八没有辨识任何新的上半身参数；模型中的上半身动力学仍是原始参数。它
证明的是命令计划、幅度、限位、回零和模型自碰撞满足进入真机试采的条件。
