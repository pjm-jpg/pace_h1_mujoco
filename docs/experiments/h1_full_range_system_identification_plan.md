# H1 全幅度系统辨识实验方案

## 1. 目标与边界

目标不是只在一个姿态附近拟合关节，而是让同一套模型同时解释：

- 小幅度、低速下的死区、库仑摩擦、编码器噪声和控制延迟；
- 大幅度下的惯量、重力、速度相关阻尼、力矩饱和与姿态依赖；
- 多关节同时运动时的动力学耦合；
- 训练动作之外的独立幅度和速度条件。

悬吊实验不能辨识脚底接触刚度、阻尼和摩擦。关节/执行器辨识与接触辨识必须分开报告，不能用悬吊数据宣称已经校准地面接触。

## 2. 要辨识的模型层

| 层 | 参数 | 主要数据 |
|---|---|---|
| 传感器与时序 | 编码器零偏、噪声、命令到状态延迟 | observe、hold、所有日志时间戳 |
| 执行器 | `kp/kd` 有效缩放、力矩限幅、速度相关降额 | step、多频、小/大幅度速度对照 |
| 关节损耗 | armature、damping、frictionloss、必要时方向非对称摩擦 | 小幅 step/multi-sine/sine |
| 刚体动力学 | 连杆质量/惯量分组缩放、质心偏置 | 大幅协调动作 |
| 耦合 | 左右腿、肩部、肩 yaw/肘、腰与全身反作用 | project-motion 组动作 |
| 接触 | 脚底刚度、阻尼、摩擦、恢复系数 | 独立的受载/力板实验 |

只使用 MuJoCo XML 中的常数 `damping + frictionloss` 可能无法同时拟合小幅和大幅数据。若残差随方向、速度或温度呈系统性变化，应保留统一刚体模型，并在执行器层加入延迟、饱和和方向相关摩擦，而不是分别生成“小幅模型”和“大幅模型”。

## 4. 分层实验矩阵

### A. 小信号局部辨识（已完成）

每个关节使用：

1. 正负阶跃或双向 step：估计静态增益、摩擦和迟滞；
2. 0.5/1/2 Hz multi-sine：估计阻尼、armature 和延迟；
3. 独立 1 Hz sine：不参与开发期拟合，用作波形验证。

开发期拟合使用 step + multi-sine；独立 sine 保留为验证集。

| 关节组 | 条件 | 与已有数据形成的对照 | MuJoCo 门控 |

0.75× 的 walk1 不安全：仿真出现跟踪超限、速度超限和自碰撞。0.65× 仍以 0.154 rad 略超跟踪阈值，因此不进入真机矩阵。

### D. 接触与受载辨识（悬吊实验之后的独立阶段）

若训练任务包含落地、行走或跳跃，仅靠当前悬吊数据不能实现完整 sim-real 一致性。推荐配置力板或已标定的足底六维力传感器后再做：

1. 吊架保护下静态加载：0/25/50/75/100% 体重，估计足底压缩和关节受载偏差；
2. 低速前后/左右剪切，估计静摩擦与动摩擦；
3. 厂商站立控制器下的小幅 squat 和 weight-shift，记录关节、IMU 与地面反力；
4. 接触数据只拟合地面与足底参数，不回头任意改动已冻结的自由空间执行器参数。

不得在当前悬吊 `LowCmd` 采集器中直接增加脚着地动作。受载实验需要独立控制器、吊架限位、急停和外部力测量。

如果没有力板/足底力传感器，接触参数应使用厂商/材料先验并在训练中做域随机化；此时只能宣称“自由空间关节动力学已校准”，不能宣称接触模型已实测辨识。

## 5. 数据隔离

### 开发训练集

- 各关节 step + multi-sine；
- 大幅协调动作的 60% 档；
- 必要时加入 90% 档，但只能在模型结构和损失权重冻结后加入最终拟合。

### 开发验证集

- 各关节独立 1 Hz sine；
- 现有 75% walk1；
- 现有 90% 大幅轨迹在首次结构选择时保持只读。

### 最终盲测集

- C 表中的四条速度对照轨迹；
- 在看到盲测结果前禁止修改模型结构、损失权重或数据对齐策略；
- 若最终合格，可在生成训练用最终模型前把验证集并入重拟合，但盲测指标必须保留原始记录。

## 6. 日志质量门槛

一条日志只有同时满足以下条件才进入正式清单：

- `result == completed`，`abort_reason == null`；
- `dropped == 0`，`malformed == 0`，`states_before_command == 0`；
- 中位状态频率不低于 450 Hz；
- 最大状态间隔不超过 20 ms；
- 在线关节跟踪误差不超过 0.15 rad；
- motor-lost 变化率不超过 0.5 Hz，并满足 burst allowance；
- 温度不超过 70°C；
- 无非有限值、无新增自碰撞、无脚或手意外接触环境。

## 7. 模型验收指标

同时报告原始 MuJoCo 与校准 MuJoCo，不只报告优化损失：

- 每关节位置 RMSE、速度 RMSE、最大误差；
- 阶跃上升时间、超调、稳态偏差；
- 正弦幅值比和相位差；
- 大幅轨迹按关节组、幅度、速度分别统计；
- 校准后相对原始 MuJoCo 的综合 RMSE 至少下降 30%；
- 小幅验证不得因大幅拟合而退化超过 10%；
- 任何单个关节不得通过其他关节平均值掩盖失败；
- 最终盲测必须在未参与调参的数据上报告。
