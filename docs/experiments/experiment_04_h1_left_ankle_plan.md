# 实验四计划：H1左踝悬空实机辨识

## 目标

辨识 `left_ankle_joint` 在当前吊装构型和真实位置PD增益下的等效
`armature`、`frictionloss` 和 `damping`。先用双向阶跃判断死区和回差，
再用多频正弦拟合，并保留独立频率与阶跃验证。

## 与膝关节实验的关键差异

- 左踝对应GO2物理电机ID 10；
- 实际增益为 `Kp=40`、`Kd=2`，显著低于膝关节的 `300/6`；
- MJCF关节范围为 `[-0.87, 0.52] rad`，准备目标为0 rad；
- 0.02 rad位置误差只对应约0.8 N·m的比例项，可能不足以克服真实静摩擦；
- 踝部辨识结果只代表悬空状态，不包含脚底接触、鞋底柔性和地面摩擦。

## 参考依据

本地Spur项目对悬空腿部采用逐关节阶跃和扫频，并指出踝部摩擦可能高于
髋、膝。其R1实验使用约 `±0.05 rad` 阶跃和 `0.03 rad` chirp。由于机器人、
传动和增益不同，本实验只把这些数值作为幅值量级参考，不直接移植参数。

## MuJoCo预演结果

已使用真实 `Kp=40`、`Kd=2`、50 Hz零阶保持和500 Hz物理步长完成：

- `±0.02 rad` 阶跃：PASS；
- `±0.03 rad` 阶跃：PASS；
- `+0.05 rad` 阶跃：PASS；
- `0.03 rad`、0.5/1/2 Hz正弦：PASS。

所有预演均无自碰撞，最小脚部点间距约0.335 m，最小关节限位余量约
0.339 rad。0.05 rad阶跃的仿真最大跟踪误差约0.056 rad，仍低于计划采用的
0.10 rad真机保护阈值。

## 真机实验顺序与决策门

### A. 小幅双向诊断

运行一次 `step`，幅值0.02 rad、重复1次。该记录在同一准备姿态下依次覆盖
正、负方向，用来检查：关节映射、物理运动方向、静摩擦、方向回差、速度、
力矩和回中能力。

通过条件：

- 确实只有左踝执行激励；
- 无异响、撞击或高频振荡；
- 最大跟踪误差小于0.10 rad；
- 电机温度低于70 °C，ID 10通信丢失计数不异常增长；
- 数据约500 Hz且无NaN/Inf。

### B. 选择正式幅值

根据0.02 rad阶跃的实测稳态变化选择：

- 实测变化 `>=0.005 rad`：正式幅值采用0.03 rad；
- 实测变化在 `0.003--0.005 rad`：正式幅值采用0.04 rad；
- 实测变化 `<0.003 rad` 且动作平稳：先做0.03 rad阶跃；若仍受死区限制，
  正式幅值最多提高到0.05 rad；
- 任一方向出现异常、跟踪误差接近0.10 rad或不能回中：停止，不提高幅值。

### C. 正式数据

确定幅值 `A` 后采集：

1. 双向阶跃 `±A`，重复1次，作为回差诊断和独立验证；
2. 0.5 Hz正弦，10秒，作为拟合数据；
3. 1.0 Hz正弦，10秒，只作独立验证；
4. 2.0 Hz正弦，10秒，作为拟合数据。

如果0.5 Hz的实际基频振幅小于0.005 rad，则不继续1/2 Hz，先重新评估幅值
和静摩擦。这样避免采集一组几乎不运动、无法辨识的数据。

## 拟合与验证

- 拟合：0.5 Hz + 2 Hz；
- 验证：1 Hz + 双向阶跃；
- 首轮只评分 `left_ankle_joint` 的位置；
- 先固定命令延迟为0，拟合 `armature/frictionloss/damping`；
- 使用第二随机种子和放宽边界复核是否稳定；
- 只有独立验证误差也下降，才接受参数并进入右踝实验。

## 安全设置

- 机器人可靠吊装、双脚完全离地，急停可立即触达；
- 停止其他所有 `rt/lowcmd` 发布者；
- 每条实验保留6秒准备、2秒稳定和6秒返回；
- 命令幅值上限保持0.05 rad；
- 真机命令显式使用 `--max-following-error-rad 0.10`；
- 每条实验完成后先离线检查，再运行下一条，不批量连续执行。
