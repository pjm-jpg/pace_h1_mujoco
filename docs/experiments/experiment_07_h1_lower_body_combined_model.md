# 实验七：H1下肢十关节合并模型与训练候选模型

## 目的

把已经完成的左右髋、膝、踝十个关节的单关节辨识结果合并到同一个H1模型，
确认合并后不会破坏各关节的回放效果，并生成一个保留自由基座、碰撞几何、
执行器、传感器和关键帧的训练候选MJCF。本阶段完全离线，不连接DDS，也不
需要机器人开机。

这里的“训练候选模型”不是最终实机模型。当前参数来自悬空单关节实验，能够
校准关节响应，但地面接触、足底摩擦、结构柔性、吊装影响和策略闭环稳定性仍
需要在策略级仿真中单独验证。

## 正式数据冻结

本阶段正式使用41个处理后数据集：十个关节各有0.5、1、2 Hz和阶跃数据，
左踝额外保留一次确认完全离地的1 Hz复测。机器可读清单位于：

```text
datasets/h1/real/lower_body_official_datasets.json
```

清单记录了每个 `.pt` 对应的原始 `raw.npz`、裁剪窗口、样本数、19关节顺序、
20槽位到19关节映射以及实际Kp/Kd。全部41个数据集的关节顺序、映射和PD增益
完全一致。两份hold诊断、中止记录、旧手臂姿态记录以及所有未列入清单的原始
日志均不参与拟合与验证。

可用以下命令重新生成并检查清单：

```bash
/home/pjm/.pixi/bin/pixi run -e mujoco \
  python datasets/freeze_h1_lower_body_dataset_manifest.py
```

汇总结果：

- 41/41组回放均优于原始MuJoCo；
- 全部回放平均RMSE从0.013194降到0.006738 rad，汇总降幅48.93%；
- 十个1 Hz保留频段的汇总降幅44.19%；
- 十个独立阶跃的平均RMSE从0.012085降到0.007603 rad，汇总降幅37.09%；
- 合并模型与各单关节模型的RMSE平均绝对差为0.000144 rad，最大差为
  0.001061 rad，说明写入同一模型后没有出现明显的参数冲突。

## 浮动基座训练候选模型

参数还写入了原始自由基座H1 MJCF，并新建独立场景：

```text
robot_model/h1/h1_calibrated_lower_body.xml
robot_model/h1/h1_calibrated_lower_body_params.json
robot_model/h1/scene_flat_calibrated_lower_body.xml
```

原始 `robot_model/h1/h1.xml` 和 `scene_flat.xml` 未被覆盖。合并工具现在支持
`--output-dir` 生成固定基座结果，也支持 `--output-xml` 将模型写到指定位置，
从而保持相对mesh路径有效。

离线验证结果：

- 原始模型与候选模型拓扑完全相同：`nq=26`、`nv=25`、`nu=19`；
- 自由基座、20个关节对象（含自由关节）、19个执行器和21个传感器均保留；
- 十个辨识参数的最大写入误差小于 `5e-12`；
- 未辨识的其余九个关节参数变化为0；
- 带地面场景运行3秒、1500步，所有状态有限，无MuJoCo warning或NaN。

短时检查中没有平衡策略，机器人会自然倒地，因此最低基座高度约0.081 m。
这个结果只验证模型编译、接触计算和数值有限，不能用来宣称模型已经能稳定
站立。验证报告位于：

```text
sysid_mujoco/results/h1/real_lower_body_combined_v1/floating_model_validation.json
```

## 结论与下一步

当前已经得到可复现的H1下肢十关节MuJoCo校准候选模型。下一步不需要重新连接
真机，应先在策略仿真中完成：

1. 将 `scene_flat_calibrated_lower_body.xml` 接入训练/评估环境；
2. 用相同策略、相同初始状态和随机种子对比原始模型与校准模型；
3. 检查跌倒率、速度跟踪、关节误差、力矩/能耗、足底滑移和接触冲击；
4. 以校准参数作为domain randomization中心，而不是固定成唯一真值；
5. 在校准模型上重新训练或微调策略，并先完成大规模仿真回归；
6. 只有策略在仿真安全检查通过后，才安排下一轮低风险真机验证。

本阶段没有辨识足底接触参数，也没有全身多关节同步激励，因此不能仅凭本次
单关节曲线就直接把新训练策略部署到真机。
